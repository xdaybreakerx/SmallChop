# Historical diagram archive

These Excalidraw sources and exported images were local WIP from October 2024.
Retain them as editable reference material. The README uses the published
`../assets/high-level.png` and `../assets/routes.png`; the copies here are kept
with the original exports rather than replacing the published images.
Editable `.excalidraw` sources belong in version control; duplicate PNG exports
are ignored and remain available locally.

The diagrams describe the original design and are not evidence of completed
reliability, health, or delivery improvements. Update the sources and published
exports together when changing architecture. Untitled files are retained with
their original names to avoid losing the provenance of the drafts.
